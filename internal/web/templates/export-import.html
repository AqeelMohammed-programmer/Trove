Export

Download the whole repository as one ZIP archive. It contains data.json and a files/ directory with the content of every copied file. The password and sessions are never included.

Import

Import is restore-only: it works only into an empty repository. The whole archive is validated before anything is changed, and the import is all-or-nothing. It does not change the password.
